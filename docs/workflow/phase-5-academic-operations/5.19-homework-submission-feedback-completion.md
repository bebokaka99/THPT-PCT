# Task 5.19 - Homework Submission & Feedback Completion

> Phase: 5
> Priority: P1
> Status: Hoàn tất

## Mục tiêu

Hoàn thiện workflow bài tập cho học sinh, giáo viên và phụ huynh theo phạm vi lớp
và enrollment. Hệ thống không tự publish nội dung ngoài policy và không dùng file
submission public.

## Đã triển khai

- Học sinh có thể nộp text, link HTTP(S), file hoặc kết hợp các loại này.
- Trạng thái gồm `not_started`, `submitted`, `late`, `returned`, `graded`.
- Giáo viên xem roster đầy đủ, kể cả học sinh chưa nộp; có thể trả bài/chấm điểm.
- Điểm được giới hạn theo `max_score`; phản hồi và điểm được lưu cùng audit.
- File nộp lưu tại `private-uploads/assignments`, chỉ tải qua endpoint có token.
- Guardian chỉ xem summary của học sinh có liên kết verified, không download file.

## API mới

- `PATCH /api/assignments/:id/submissions/:submissionId/review`
- `GET /api/assignments/:id/submissions/:submissionId/files/:fileId/download`
- `GET /api/assignments/guardian/students/:studentId`
