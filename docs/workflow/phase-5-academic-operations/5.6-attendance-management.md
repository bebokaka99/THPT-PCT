# Task 5.6 — Attendance Management

> **Trạng thái:** ✅ Hoàn thành  
> **Yêu cầu trước:** 5.3, 5.4, timetable

## Mục tiêu

Teacher điểm danh theo ngày/tiết; student xem chuyên cần của chính mình; admin
và giáo viên chủ nhiệm theo dõi tổng hợp.

## Phạm vi

- Attendance sessions/records: present, excused, unexcused, late.
- Teacher tạo/điểm danh lớp được phân công.
- Homeroom/admin chỉnh lý do theo policy và audit.
- Student tab “Chuyên cần”; teacher tab “Điểm danh”.
- Notification tùy chọn khi vắng/đi trễ.

## Rule bắt buộc

- Unique student/session.
- Bulk save transaction; không mất dữ liệu khi một row lỗi.
- Mọi sửa sau ngày học có audit actor/reason.
- Student chỉ đọc record của mình.

## Tự kiểm tra

- [x] Full/partial class attendance
- [x] Foreign class 403
- [x] Audit correction
- [x] Monthly/semester totals correct
