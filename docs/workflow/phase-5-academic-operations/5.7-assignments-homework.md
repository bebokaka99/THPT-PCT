# Task 5.7 - Assignments & Homework

> **Trang thai:** Hoan thanh ngay 2026-07-26  
> **Yeu cau truoc:** 5.4, Media

## Muc tieu

Teacher giao bai theo mon/lop; student theo doi han va nop file co ban.

## Pham vi da hoan thanh

- Assignments, attachments, submissions, submission files va submission audit.
- Trang thai `draft`, `published`, `closed`; backend xac dinh `submitted`/`late`.
- Teacher CRUD trong dung `teaching_assignment_id` cua minh.
- Student xem bai theo enrollment va nop/thay file theo policy.
- Teacher xem danh sach bai nop; chua cham diem tich hop gradebook.
- Admin co trang giam sat bai tap toan truong.

## Rule bat buoc

- Assignment luon tham chieu teaching assignment, classroom, subject va semester.
- Teacher khong duoc tao/quan ly bai ngoai phan cong.
- Student chi thay bai published/closed cua lop minh tai ngay publish.
- Deadline luu `TIMESTAMPTZ`; backend so sanh thoi diem, UI hien theo timezone local.
- File toi da 10 MB: jpg, jpeg, png, webp, pdf, doc, docx, xls, xlsx.
- Thay bai nop khong xoa vat ly phien ban cu; file cu chuyen `is_active=false`.
- Moi submit/replace ghi audit actor, old/new status va old/new file.
- Upload that bai transaction duoc compensate, khong de media/file mo coi.
- Publish assignment tao notification cho roster hoc sinh dung tai ngay publish.
