# Task 5.5 - Assessment Configuration

> **Trạng thái:** Hoàn thành ngày 2026-07-26  
> **Yêu cầu trước:** Task 5.1, 5.2, 5.4

## Mục tiêu

Cấu hình loại đầu điểm và công thức theo môn, khối, học kỳ trước khi xây
gradebook; không hardcode cột điểm hoặc công thức ở frontend.

## Phạm vi đã hoàn thành

- Root configuration theo `subject + grade_level + semester`.
- Version tăng dần, trạng thái `draft`, `active`, `archived`.
- Category gồm mã, tên, trọng số, hệ số, số lần tối đa, thang điểm và thứ tự.
- Admin tạo/sửa draft, activate, tạo version mới và xóa draft.
- Teacher chỉ xem cấu hình active thuộc môn được phân công.
- Backend calculator preview dùng chính cấu hình đã lưu.
- Database trigger bảo vệ scope, tổng trọng số và lịch sử đã kích hoạt.

## Rule bắt buộc

- Mỗi scope chỉ có tối đa một draft và một active version.
- Tổng `weight_percent` phải bằng đúng 100.
- Category code unique trong một version.
- Chỉ draft được sửa hoặc xóa.
- Active chỉ có thể chuyển thành archived khi version mới được activate.
- Archived không thể re-activate hoặc sửa nội dung.
- Học kỳ/năm học đóng hoặc khóa chặn create, edit, version và activate.
- Subject phải active trong curriculum đúng năm học và khối.
- Teacher phải có teaching assignment active đúng subject/semester/grade.
- Frontend không gửi hoặc tự quyết định kết quả cuối cùng.

## Công thức

Với mỗi category:

```text
category_average = sum(scores) / number_of_scores
normalized_score = category_average / category_score_scale * result_score_scale
weighted_score = normalized_score * weight_percent / 100
raw_score = sum(weighted_score)
final_score = round(raw_score, decimal_places, rounding_mode)
```

Ví dụ:

```text
TX: (8 + 9) / 2 = 8.5, weight 40% => 3.4
CK: 7.5, weight 60% => 4.5
raw/final = 7.9
```

Rounding mode:

- `half_up`: phần đúng 0.5 làm tròn lên.
- `half_even`: phần đúng 0.5 về số chẵn gần nhất.
- `truncate`: cắt phần dư theo số chữ số cấu hình.

Configuration dùng PostgreSQL `NUMERIC(..., 2)`. Calculator giữ intermediate
đến 6 chữ số và trả final từ 0 đến 2 chữ số thập phân.

## UI

- Admin: `/admin/assessment-configurations`
  - chọn semester, grade và subject từ curriculum;
  - thêm/xóa category;
  - kiểm tra tổng trọng số;
  - tạo/sửa draft, activate và tạo version.

  - chỉ thấy active configuration thuộc assignment của mình;
  - xem category/rule;
  - nhập điểm mẫu và gọi backend calculator.
