# Task 5.14 - Academic Import/Export & Reports

> **Trạng thái:** Hoàn thành bản v1 ngày 2026-07-30  
> **Yêu cầu trước:** 5.1-5.13

## Mục tiêu

Hỗ trợ vận hành dữ liệu học vụ số lượng lớn bằng CSV tương thích Excel, luôn có
bước preview/validation trước khi ghi database và không cho phép commit một phần.

## Đã triển khai

- Template, preview và commit cho:
  - xếp lớp học sinh;
  - bài tập;
  - chuyên cần;
  - điểm số.
- Validation theo từng dòng, file lỗi CSV, idempotency key và audit job.
- Export danh sách lớp, chuyên cần, sổ điểm và tổng hợp học bạ.
- Báo cáo tổng quan theo năm học/học kỳ/lớp/môn.
- Trang admin `/admin/academic-operations`.
- File CSV UTF-8 có BOM để Excel đọc đúng tiếng Việt.

## Quy tắc bắt buộc

- Chỉ admin có quyền `academic_imports.manage` hoặc
  `academic_reports.export` mới được truy cập.
- File tối đa 2 MB, 2.000 dòng, chỉ nhận CSV.
- Không lưu file nguồn và không log nội dung CSV/PII.
- Không chạy công thức/macro; ô bắt đầu bằng `=`, `+`, `-`, `@` bị từ chối.
- Job có dòng lỗi không được commit.
- Enrollment/assignment commit trong một transaction.
- Attendance và grade gọi service hiện hữu để giữ scope, khóa học kỳ, optimistic
  version và audit.
- Import điểm chỉ ghi vào gradebook `draft`; không bypass workflow
  submit/approve/lock.

## Tự kiểm tra

- [x] File hợp lệ và file có lỗi.
- [x] Retry cùng idempotency key không tạo job/dữ liệu trùng.
- [x] Reuse key với file khác trả `409`.
- [x] File 1.001 dòng được parse và validation.
- [x] Non-admin trả `403`.
- [x] Commit nguyên khối và audit.
- [x] CSV export có UTF-8 BOM.
- [x] Backend/frontend build.
- [x] Migration và seed quyền.

## Giới hạn v1

- Parse/validation/commit đang chạy đồng bộ trong request và giới hạn 2.000 dòng.
  Trước khi nâng giới hạn phải bổ sung queue/worker, object storage tạm, retry,
  progress và cơ chế phục hồi job bị gián đoạn.
- Chỉ hỗ trợ CSV. Không dùng thư viện XLSX có dependency audit rủi ro.
- UI export v1 dùng ID để tránh kéo thêm nhiều bộ chọn lớn.
- Chưa có lịch chạy báo cáo hoặc gửi báo cáo qua email.
