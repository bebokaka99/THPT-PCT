# Task 3.1 — React Query Integration

> **Phase:** 3 — Frontend Stabilization
> **Trạng thái:** ✅ Hoàn thành
> **Độ khó:** Trung bình
> **Yêu cầu trước:** Task 1.4 (error handling foundation)

## Mục tiêu

Chuẩn hóa cache, loading và retry cho các luồng đọc dữ liệu public mà không
rewrite toàn bộ routing hoặc admin UI.

## Phạm vi thực hiện

- Cài `@tanstack/react-query`.
- Tạo một `QueryClient` dùng chung với:
  - cache mặc định 30 giây;
  - garbage collection sau 5 phút;
  - retry một lần;
  - không tự refetch khi đổi focus cửa sổ.
- Bọc ứng dụng bằng `QueryClientProvider`.
- Chuyển `HomePage`, `PostsPage` và `DocumentsPage` sang `useQuery`.
- Giữ nguyên API services, query string, phân trang, filter và UI states hiện có.
- Dùng query key chứa đầy đủ page/search/filter để tránh trả nhầm cache.

## Lưu ý kiến trúc

Admin pages và các portal page vẫn dùng flow hiện tại trong task này để giới
hạn thay đổi. Các nhóm đó sẽ được chuyển dần khi có mutation/query key riêng,
tránh tạo một đợt refactor lớn khó kiểm chứng.
