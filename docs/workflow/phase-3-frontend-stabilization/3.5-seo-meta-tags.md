# Task 3.5 — SEO Meta Tags

> **Phase:** 3 — Frontend Stabilization
> **Trạng thái:** ✅ Hoàn thành
> **Độ khó:** Trung bình
> **Yêu cầu trước:** Public routes và dữ liệu bài viết/tài liệu hoạt động

## Mục tiêu

Thiết lập metadata SEO cơ bản cho public website, metadata động cho trang chi
tiết và ngăn index các trang đăng nhập/nội bộ mà không thêm dependency mới.

## Thay đổi đã thực hiện

- Tạo component `Seo` dùng chung để quản lý:
  - document title;
  - meta description và robots;
  - Open Graph;
  - Twitter Card;
  - canonical URL;
  - `article:published_time` cho nội dung chi tiết.
- Public pages có metadata riêng:
  - trang chủ;
  - danh sách và chi tiết tin tức;
  - danh sách và chi tiết tài liệu;
  - danh mục;
  - tìm kiếm.
- Trang tìm kiếm, đăng nhập và toàn bộ protected route dùng `noindex`.
- Trang chi tiết dùng title, description, ảnh cover và thời gian xuất bản từ
  dữ liệu API.
- Bổ sung metadata mặc định trong `index.html` để document ban đầu vẫn có thông
  tin hợp lệ trước khi React mount.
- Thêm `robots.txt`.
- Thêm `VITE_PUBLIC_SITE_URL` vào file môi trường mẫu để tạo canonical URL đúng
  khi deploy.

## Cấu hình

```env
VITE_PUBLIC_SITE_URL=https://ten-mien-production.example
```

Nếu biến này không tồn tại, local development dùng `window.location.origin`.

## Giới hạn hiện tại

- Đây vẫn là SPA client-rendered. Bot không chạy JavaScript chỉ đọc được
  metadata mặc định trong `index.html`, không đọc metadata động theo từng bài.
- Cần SSR hoặc prerender ở phase production nếu yêu cầu SEO/social preview cho
  từng URL ở mức đầy đủ.
- Chưa tạo sitemap vì chưa chốt domain production và chiến lược URL canonical.
- Production bắt buộc cấu hình `VITE_PUBLIC_SITE_URL` bằng origin public thật.
