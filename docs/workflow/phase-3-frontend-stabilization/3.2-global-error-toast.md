# Task 3.2 — Global Error & Toast System

> **Phase:** 3 — Frontend Stabilization
> **Trạng thái:** ✅ Hoàn thành
> **Độ khó:** Trung bình
> **Yêu cầu trước:** Task 1.4 (error handling foundation)

## Mục tiêu

Hoàn thiện feedback toàn cục cho lỗi API và thao tác thành công, không bắt
buộc từng page phải tự xây một notification system riêng.

## Phạm vi thực hiện

- Giữ `ToastProvider` ở cấp App và tiếp tục nhận API error event từ
  `api-client`.
- Bổ sung các helper dễ dùng:
  - `success(message)`
  - `error(message)`
  - `info(message)`
  - `clearToasts()`
- Chặn duplicate toast cùng loại và cùng nội dung.
- Giới hạn tối đa bốn toast đang hiển thị.
- Tự dọn timer khi toast bị đóng hoặc provider unmount.
- Bổ sung success feedback cho:
  - lưu/tạo bài viết;
  - tạo/cập nhật/xóa danh mục.
- Giữ `ErrorBoundary` làm fallback cuối cùng cho lỗi render không thể phục hồi.
