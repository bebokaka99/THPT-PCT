# Task 4.7 — Media Image Optimization

> **Trạng thái:** ✅ Hoàn thành ngày 2026-07-25  
> **Yêu cầu trước:** Media upload, profile avatar, event/post cover

## Mục tiêu

Giảm dung lượng ảnh và chuẩn hóa derivative phục vụ card, cover, gallery,
avatar mà không làm mất file gốc.

## Phạm vi

- Chọn thư viện xử lý ảnh duy nhất, ưu tiên `sharp`.
- Validate magic bytes, không chỉ mimetype/extension.
- Tạo thumbnail/medium WebP hoặc AVIF theo cấu hình.
- Giữ original; lưu metadata dimensions/variants.
- Không upscale ảnh nhỏ, tự xoay theo EXIF, bỏ metadata nhạy cảm.
- Cập nhật Media API/UI để dùng variant phù hợp.
- Job backfill cho ảnh cũ, chạy idempotent.

## Report - 2026-07-25

- Thêm package backend `sharp`.
- Thêm migration PostgreSQL `019_media_image_variants.sql`.
- Ảnh upload dùng Multer memory storage, được decode bằng `sharp` trước khi
  ghi media record.
- Giữ file gốc và tạo hai derivative WebP:
  - `thumbnail`: chiều rộng tối đa 320px, quality 78.
  - `medium`: chiều rộng tối đa 1280px, quality 82.
- Không upscale ảnh nhỏ; giữ tỉ lệ và tự xoay theo EXIF. Derivative không giữ
  metadata EXIF.
- API media trả thêm `width`, `height`, `optimized_size`, `variants`.
- Admin Media và Media Picker dùng thumbnail để preview, medium để chọn ảnh.
- Profile avatar lưu URL medium nếu derivative tạo thành công.
- DB lỗi sau khi ghi file sẽ xóa cả original và derivative.
