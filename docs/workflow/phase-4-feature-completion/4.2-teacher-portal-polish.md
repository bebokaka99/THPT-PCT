## Workflow publish

UI luôn tạo nội dung mới dưới trạng thái `draft`. Nếu giáo viên chọn đăng ngay,
frontend gọi tiếp endpoint publish:

```text
POST draft -> PATCH publish
```

Điều này bảo đảm backend tạo notification cho học sinh. UI cũ tạo trực tiếp
`published`, khiến notification hook không chạy.
