# Task 4.3 — Notification Center UI

> **Phase:** 4 — Feature Completion  
> **Trạng thái:** ✅ Hoàn thành  
> **Độ khó:** Trung bình  
> **Yêu cầu trước:** Auth refresh, React Query và notification API

## Mục tiêu

Tạo một trung tâm thông báo dùng chung cho admin, giáo viên và học sinh; đồng
bộ trạng thái đọc với chuông thông báo trên Header mà không thay đổi backend
contract hiện có.

## Thay đổi frontend

- Thêm route protected `/notifications` cho role `admin`, `teacher`, `student`.
- Trang Notification Center:
  - danh sách có pagination;
  - filter tất cả/chưa đọc lưu trên URL;
  - unread count;
  - đánh dấu từng thông báo là đã đọc;
  - đánh dấu tất cả là đã đọc;
  - loading, error, retry và empty states;
  - mở `related_url` sau khi cập nhật trạng thái đọc;
  - link quay lại portal phù hợp role.
- Header:
  - dùng React Query thay cho notification state cục bộ;
  - polling mỗi 60 giây;
  - badge chưa đọc;
  - phân biệt notification mới;
  - action đọc tất cả và link xem toàn bộ;
  - mobile menu có link thông báo và unread badge.
- Query invalidation dùng chung nên Header, trang Notification Center và unread
  count cập nhật cùng lúc.
- `related_url` chỉ cho phép internal path hoặc HTTP/HTTPS URL.

## Backend contract đã xác nhận

```text
GET   /api/notifications/me
GET   /api/notifications/me/unread-count
PATCH /api/notifications/me/:id/read
PATCH /api/notifications/me/read-all
```

Các endpoint đều yêu cầu access token. API đánh dấu đọc nhận
`notifications.id`, không phải `user_notifications.id`.

## Cách kiểm tra local

1. Chạy backend tại `http://localhost:4001`.
2. Chạy frontend tại `http://localhost:5173`.
3. Đăng nhập tài khoản có role admin, teacher hoặc student.
4. Bấm chuông trên Header hoặc mở `/notifications`.
5. Chuyển filter `Tất cả`/`Chưa đọc`, mở một mục và thử `Đánh dấu tất cả đã đọc`.
