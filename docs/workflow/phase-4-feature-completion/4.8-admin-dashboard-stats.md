học vụ; thống kê điểm/chuyên cần thuộc Phase 5.

## Phạm vi

- Một overview endpoint thay cho nhiều request.
- Số user theo role/status, lớp active, nội dung theo trạng thái.

- Dashboard responsive, loading/error/empty.

nếu cần tách quyền chỉ đọc.
