# Task 4.4 — Profile Management

> **Phase:** 4 — Feature Completion  
> **Trạng thái:** ✅ Hoàn thành  
> **Độ khó:** Trung bình  
> **Yêu cầu trước:** Teacher/Student Portal, Media upload và React Query

## Mục tiêu

Hoàn thiện luồng tự quản lý hồ sơ cho giáo viên và học sinh, đặc biệt là avatar
upload an toàn mà không cấp quyền quản lý Media rộng cho student.

## Backend

### Endpoint mới

```text
POST /api/profiles/me/avatar
Content-Type: multipart/form-data
Field: file
```

- Yêu cầu đăng nhập và phải có teacher/student profile.
- Chỉ nhận JPG, JPEG, PNG, WebP.
- Giới hạn 5 MB.
- Lưu file vào `backend/uploads/images`.
- Tạo media record với `uploaded_by` là user hiện tại.
- Cập nhật `avatar_url` trực tiếp vào profile.
- Preflight profile trước Multer để request không hợp lệ không tạo file mồ côi.

### Hardening profile

- PATCH `/api/profiles/me` có semantics partial đúng:
  - field không gửi được giữ nguyên;
  - `null` hoặc chuỗi rỗng mới dùng để xóa field;
  - profile chưa thiết lập trả 404 rõ ràng.
- Validate:
  - phone/parent phone tối đa 50 ký tự và chỉ nhận ký tự điện thoại;
  - avatar chỉ nhận HTTP/HTTPS hoặc `/uploads/images/...`;
  - bio tối đa 2.000 ký tự;
  - chặn local path và `file://`.
- Tách Multer config dùng chung thành `media-upload.ts`; Media upload cũ vẫn giữ
  giới hạn 10 MB và permission hiện có.

## Frontend

- Component dùng chung `ProfileAvatarEditor`:
  - upload avatar;
  - nhập URL thủ công;
  - gỡ avatar;
  - client validation file type/5 MB;
  - loading/error/toast.
- Teacher profile:
  - upload avatar;
  - phone có giới hạn;
  - bio có bộ đếm 2.000 ký tự.
- Student profile:
  - upload avatar không cần quyền Media;
  - phone và parent phone có giới hạn.
- Avatar cập nhật ngay qua React Query cache trên:
  - trang profile;
  - sidebar teacher/student;
  - account chip Header desktop/mobile.
- Chuẩn hóa URL `/uploads/...` bằng helper dùng chung.
