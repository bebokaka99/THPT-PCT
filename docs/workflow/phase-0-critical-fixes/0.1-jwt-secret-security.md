# Task 0.1 — JWT Secret Security

> **Phase:** 0 — Critical Fixes
> **Trạng thái:** ✅ Hoàn thành
> **Độ khó:** Thấp
> **Thời gian ước tính:** 30 phút
> **Risk nếu không làm:** 🔴 CRITICAL — Token có thể bị forge trong production
> **Yêu cầu trước:** Không

---

## Mô tả vấn đề

File `backend/src/config/env.ts` hiện tại:
```ts
jwt: {
  secret: process.env.JWT_SECRET ?? 'change_me_in_development',
  expiresIn: process.env.JWT_EXPIRES_IN ?? '1d',
}
```

File `backend/.env` hiện tại **KHÔNG CÓ** `JWT_SECRET` và `JWT_EXPIRES_IN` → backend sẽ dùng default secret `'change_me_in_development'`. Bất kỳ ai biết secret này đều có thể tạo token giả mạo bất kỳ user nào.

---

## Mục tiêu

1. Backend phải **REJECT** khởi động nếu `JWT_SECRET` là default value trong production
2. `.env.example` phải hướng dẫn rõ ràng
3. `.env` phải có `JWT_SECRET` thực tế

---

## Cách thực hiện

### Plan A — Thêm startup validation (KHUYẾN NGHỊ)

**Bước 1:** Sửa `backend/src/config/env.ts`

```ts
import dotenv from 'dotenv';
import path from 'node:path';

dotenv.config({ path: path.resolve(process.cwd(), '.env') });

const jwtSecret = process.env.JWT_SECRET ?? 'change_me_in_development';
const isProduction = process.env.NODE_ENV === 'production';

if (isProduction && jwtSecret === 'change_me_in_development') {
  console.error('FATAL: JWT_SECRET must be set in production. Do not use the default value.');
  process.exit(1);
}

if (jwtSecret === 'change_me_in_development') {
  console.warn('WARNING: Using default JWT_SECRET. Set JWT_SECRET in .env for security.');
}

export const env = {
  port: Number(process.env.PORT ?? 4000),
  database: {
    host: process.env.DB_HOST ?? 'localhost',
    port: Number(process.env.DB_PORT ?? 3306),
    user: process.env.DB_USER ?? 'root',
    password: process.env.DB_PASSWORD ?? '',
    name: process.env.DB_NAME ?? 'thpt_pct_pt',
  },
  jwt: {
    secret: jwtSecret,
    expiresIn: process.env.JWT_EXPIRES_IN ?? '1d',
  },
};
```

**Bước 2:** Cập nhật `backend/.env.example`

```env
PORT=4000
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=
DB_NAME=thpt_pct_pt
JWT_SECRET=thay-bang-chuoi-ngau-nhien-toi-thieu-32-ky-tu
JWT_EXPIRES_IN=1d
```

**Bước 3:** Cập nhật `backend/.env` — thêm JWT_SECRET thực tế

```env
JWT_SECRET=dev-local-secret-thpt-pct-pt-2026
JWT_EXPIRES_IN=1d
```

**Bước 4:** Verify

```bash
cd backend
npm run dev
# Kiểm tra console có WARNING về JWT_SECRET không
# Nếu có → thay secret thật
# Nếu server chạy bình thường → OK
```

### Plan B — Nếu Plan A gây crash startup

**Lý do có thể xảy ra:** `process.env.NODE_ENV` chưa được set, hoặc dotenv chưa load kịp.

**Cách xử lý:**
- Đảm bảo `dotenv.config()` chạy TRƯỚC khi check
- Thay `process.exit(1)` bằng `throw new Error(...)` nếu muốn error stack trace
- Nếu vẫn crash: chỉ log warning, không block startup — tuy nhiên phải fix .env ngay

### Plan C — Nếu .env bị git track

**Kiểm tra:** Xem `.gitignore` có `.env` chưa
```bash
grep -n ".env" .gitignore
```
Nếu chưa có → thêm `backend/.env` vào `.gitignore`
