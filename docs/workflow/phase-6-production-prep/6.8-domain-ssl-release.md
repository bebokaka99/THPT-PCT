# Task 6.8 — Domain, SSL & Production Release

> **Trạng thái:** ⏳ Chưa thực hiện  
> **Yêu cầu trước:** 6.1–6.7

## Mục tiêu

Phát hành production có TLS, domain, rollback và checklist vận hành.

## Phạm vi

- DNS, HTTPS/TLS renewal, reverse proxy/CDN.
- Secure cookies, HSTS sau khi xác nhận HTTPS.
- Production migration/seed policy.
- Smoke theo admin/teacher/student/public.
- Maintenance window, communication, rollback.
- Post-release monitoring và ownership.

## Tự kiểm tra

- [ ] SSL/domain/canonical URL
- [ ] Headers/cookies/CORS production
- [ ] Backup ngay trước release
- [ ] Role smoke tests
- [ ] Rollback command verified
- [ ] 24h post-release review
