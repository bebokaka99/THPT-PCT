# Task 6.3 - CI/CD Pipeline

> **Trạng thái:** Đã hoàn thiện source và local gates; chờ cấu hình/kiểm chứng trên GitHub  
> **Yêu cầu trước:** 6.2

## Mục tiêu

Tự động hóa quality gates, tạo container image bất biến theo commit SHA, triển
khai có smoke test và rollback phiên bản ứng dụng.

## Phạm vi đã triển khai

- `.github/workflows/ci.yml` chạy backend quality, migration contract, frontend
  build, dependency audit, container build và Trivy scan.
- Image backend, frontend và PostgreSQL được gắn full commit SHA. Chỉ push GHCR
  khi workflow chạy từ nhánh `main`.
- Release manifest ghi commit, repository, run ID và ba image reference.
- `.github/workflows/deploy.yml` hỗ trợ staging tự động sau Quality Gate và
  production manual dispatch qua GitHub Environments.
- `tools/deploy-release.sh`, `tools/smoke-deployment.sh` và
  `tools/rollback-release.sh` triển khai app image, kiểm tra health và quay về
  release trước.
- Migration vẫn do backend entrypoint chạy dưới PostgreSQL advisory lock.
  Rollback chỉ đổi backend/frontend image, không rollback database.
- `docs/cicd-deployment.md` là runbook cấu hình runner, environment, deploy và
  rollback.
