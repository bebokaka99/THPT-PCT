# Task 6.4 — Environment & Secrets Management

> **Trạng thái:** ⏳ Chưa thực hiện  
> **Yêu cầu trước:** Security baseline

## Mục tiêu

Chuẩn hóa development/staging/production config và quản lý secret.

## Phạm vi

- Typed env schema và startup fail-fast.
- Secret manager hoặc platform secrets.
- JWT/database/CORS/cookie/URL config theo environment.
- Rotation runbook; không commit `.env`.
- Frontend chỉ chứa biến public `VITE_*`.

## Tự kiểm tra

- [ ] Missing/unsafe env fail
- [ ] Secret không xuất hiện bundle/log/image
- [ ] Rotation không downtime theo runbook
- [ ] `.env.example` và docs đồng bộ
