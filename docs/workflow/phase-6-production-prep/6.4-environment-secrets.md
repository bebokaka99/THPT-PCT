# Task 6.4 — Environment & Secrets Management

> **Trạng thái:** 🚧 Đang kiểm tra
> **Yêu cầu trước:** 6.1 Security baseline, CI source của 6.3

## Mục tiêu

Chuẩn hóa development/staging/production config và quản lý secret.

## Phạm vi

- Typed env schema và startup fail-fast.
- Secret manager hoặc platform secrets.
- JWT/database/CORS/cookie/URL config theo environment.
- Rotation runbook; không commit `.env`.
- Frontend chỉ chứa biến public `VITE_*`.

## Phạm vi đã triển khai

- Backend typed parser cho environment, URL, enum, integer và boolean.
- `APP_ENV` tách deployment stage khỏi `NODE_ENV` runtime.
- Staging/production fail-fast với JWT, database, CORS, public URL và cookie.
- JWT key ring hỗ trợ rotation không downtime bằng `JWT_PREVIOUS_SECRETS`.
- Frontend gom public env tại `src/config/public-env.ts`.
- CI scan source/frontend bundle và inspect image metadata, không in secret.
- Deploy materialize `DEPLOY_ENV_B64` trong runner temp với mode owner-only và
  xóa sau mọi kết quả.
- Runbook `docs/environment-secrets.md` mô tả phân loại, setup và rotation.

và GitHub image gate đều pass. Secret thật không được dùng làm dữ liệu test.
