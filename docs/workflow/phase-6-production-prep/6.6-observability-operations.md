# Task 6.6 — Observability & Operations

> **Trạng thái:** ⏳ Chưa thực hiện  
> **Yêu cầu trước:** Logging foundation, deployment environment

## Mục tiêu

Theo dõi lỗi, hiệu năng và sức khỏe hệ thống mà không log PII.

## Phạm vi

- Structured logs, request ID xuyên suốt proxy/backend.
- Error tracking, uptime checks, metrics DB/API.
- Alerts cho 5xx, latency, DB pool, disk/uploads, backup.
- Admin operational health không lộ secret.
- Incident/runbook và log retention.

## Tự kiểm tra

- [ ] Synthetic failure tạo alert
- [ ] Request trace được end-to-end
- [ ] PII/log redaction test
- [ ] Health/readiness phân biệt
