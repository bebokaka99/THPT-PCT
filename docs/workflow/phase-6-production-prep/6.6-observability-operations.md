# Task 6.6 - Observability & Operations

> **Status:** Source/local gate da hoan thanh; production monitoring va alerting con cho owner van hanh
> **Dependency:** Task 6.1, 6.2, 6.3, 6.4 va 6.5

## Muc tieu

Theo doi request, health, database, latency va loi ky thuat ma khong ghi PII
hoac secret vao log/metrics. Co runbook de owner ket noi monitor production.

## Pham vi da trien khai

- Request ID duoc nhan tu proxy khi hop le, phat sinh neu thieu va tra lai qua
  `X-Request-Id`.
- Pino structured logging co redaction auth/token/password/body va PII pho bien;
  request log bo query string.
- Metrics in-memory khong PII: status buckets, active/aborted requests,
  average/max va p95 latency trong 5 phut, slow requests va toi da 25 error
  fingerprints.
- Health routes:
  - `GET /api/health` legacy liveness;
  - `GET /api/health/live` khong phu thuoc database;
  - `GET /api/health/ready` kiem tra database va tra 503 neu not ready;
  - `GET /api/health/db` legacy database check.
- Admin operation API `GET /api/operations/health`, chi role admin, khong tra
  PII/secret; synthetic failure `POST /api/operations/synthetic-failure` co
  guard cau hinh.
- Frontend admin co `/admin/system-health`, tu refresh 30 giay.
- Docker Compose log rotation 10 MB x 5 file moi service.
- Runbook day du tai `docs/observability-operations.md`.
