# Task 6.5 — Database Backup & Restore Strategy

> **Trạng thái:** ⏳ Chưa thực hiện  
> **Yêu cầu trước:** PostgreSQL production design

## Mục tiêu

Có backup tự động và chứng minh restore được, không chỉ tạo file backup.

## Phạm vi

- RPO/RTO, daily backup, retention và encryption.
- `pg_dump`/managed snapshots phù hợp.
- Upload/media backup consistency.
- Restore vào môi trường cô lập và data integrity checks.
- Migration rollback/forward recovery runbook.
