# Task 6.5 - Database Backup & Restore Strategy

> **Status:** Source va local restore drill da hoan thanh; production schedule dang cho runner/offsite storage
> **Dependency:** PostgreSQL production design, Task 6.2 va deployment runner cua Task 6.3

## Muc tieu

Co backup tu dong, ma hoa, co checksum va chung minh restore duoc. Backup phai
bao gom PostgreSQL cung public/private uploads, khong chi tao mot file dump.

## Pham vi da trien khai

- `tools/backup-postgres.mjs`: pause backend, `pg_dump` custom format, archive
  uploads, AES-256-GCM, SHA-256, manifest row counts va retention.
- `tools/restore-postgres.mjs`: verify checksum/authentication/catalog/archive,
  restore vao database co lap, so sanh row counts va safe in-place guard.
- `.github/workflows/backup.yml`: daily encrypted backup, weekly restore drill va
  manual dispatch tren production self-hosted runner.
- `docs/database-backup-restore.md`: RPO/RTO, key management, command, recovery,
  monitoring va external storage requirement.
