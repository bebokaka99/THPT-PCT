# Task 6.1 - Production Security & Privacy Audit

> **Trạng thái:** Hoàn thành ngày 2026-07-30  
> **Yêu cầu trước:** Phase 5 hoàn thành

## Mục tiêu

Audit quyền truy cập, session, upload, dependency và dữ liệu cá nhân trước khi
đóng gói production. Mọi finding phải có severity, trạng thái, owner và điều
kiện release.

## Phạm vi đã thực hiện

- Lập RBAC/ownership matrix theo nhóm API.
- Kiểm tra auth, refresh rotation, CORS, rate limit, SQL parameterization, XSS
  sanitization, upload và error handling.
- Kiểm kê PII, đề xuất retention và production release gate.
- Vá session revocation, log redaction, upload magic bytes, password policy,
  cookie/cache và PostgreSQL TLS certificate validation.
- Chạy dependency audit backend/frontend.
- Thêm smoke test bảo mật vào `npm run quality`.
