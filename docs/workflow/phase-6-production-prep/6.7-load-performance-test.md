# Task 6.7 — Load & Performance Test

> **Trạng thái:** ⏳ Chưa thực hiện  
> **Yêu cầu trước:** Staging gần production, observability

## Mục tiêu

Xác nhận portal chịu được tải dự kiến giờ cao điểm nhập điểm/xem kết quả.

## Phạm vi

- Kịch bản public read, login, gradebook save, transcript, upload.
- Dataset gần quy mô trường thật.
- Define latency/error SLO.
- Query plans/indexes, pool sizing, cache/CDN.
- Không load test production nếu chưa phê duyệt.

## Tự kiểm tra

- [ ] Baseline và target concurrency
- [ ] No data corruption under concurrent writes
- [ ] DB pool không exhaustion
- [ ] Bottleneck report và rerun sau fix
