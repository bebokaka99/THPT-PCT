# Task 6.2 - Docker Setup

> **Trạng thái:** Hoàn thành ngày 2026-07-31  
> **Yêu cầu trước:** Task 6.1 hoàn thành

## Mục tiêu

Đóng gói frontend, backend và PostgreSQL thành stack nhất quán, không bake
secret, có healthcheck, persistent volume và baseline container security.

## Đã triển khai

- Multi-stage Dockerfile cho backend và frontend.
- Backend runtime non-root, read-only root filesystem, drop capabilities.
- Nginx unprivileged phục vụ SPA và proxy `/api`, `/uploads`.
- Backend entrypoint chạy migration/seed trước khi start.
- PostgreSQL, public upload và private upload dùng named volumes riêng.
- Healthcheck cho cả ba services.
- Graceful shutdown backend khi nhận `SIGTERM`/`SIGINT`.
- `.dockerignore`, `.env.docker.example` và runbook.
- Script `tools/verify-docker.ps1` kiểm tra clean build, health, migration,
  non-root, persistence và Trivy scan.
- Frontend hỗ trợ relative API base `/api` và media URL same-origin.

## Trạng thái xác minh

Docker Desktop 4.84.0, WSL 2.7.11 và Trivy 0.72.0 đã được cài ngày
2026-07-31. Clean build, Compose startup, migration, health, non-root,
database/upload persistence và image scan đều đã chạy thật.

Trivy ban đầu phát hiện CVE trong npm CLI của backend runtime, Nginx 1.28.1 và
official PostgreSQL images. Runtime backend đã bỏ npm/corepack/Yarn; frontend
đã nâng lên Nginx unprivileged 1.30.4-alpine3.24; PostgreSQL dùng custom image
từ official 18.4-alpine3.23, security upgrade và thay `gosu` bằng `su-exec`.
Ba final images đều có 0 HIGH/CRITICAL tại thời điểm xác minh.

Lệnh đóng gate trên host có Docker:

```powershell
Copy-Item .env.docker.example .env.docker
# Điền hai secret bắt buộc
powershell -ExecutionPolicy Bypass -File tools/verify-docker.ps1
```
