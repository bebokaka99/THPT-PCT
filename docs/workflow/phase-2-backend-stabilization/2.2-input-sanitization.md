> **Phase:** 2 — Backend Stabilization

> **Thời gian ước tính:** 1-2 giờ

> **Yêu cầu trước:** Task 1.1 (shared validators)

---

## Mô tả vấn đề

1. **SQL:** Tất cả queries dùng parameterized `?` → an toàn. Ngoại trừ `findAuthUserByColumn` dùng `u.${column}` — tuy column chỉ là `'id'` hoặc `'email'` (hardcoded) nhưng pattern nguy hiểm.
2. **XSS:** Post `content` field chứa HTML (từ TipTap editor + importer) → cần sanitize khi render. Frontend dùng `dompurify` — cần verify đang sanitize đúng chỗ.
3. **Search queries:** `LIKE '%${query}%'` — params đã escaped nhưng cần verify.

---

## Mục tiêu

1. Audit & fix `findAuthUserByColumn` dynamic column
2. Verify DOMPurify đang dùng đúng chỗ frontend
3. Thêm HTML sanitization cho imported content trên backend
4. Review tất cả SQL queries cho potential injection

## Cách thực hiện

### Plan A — Fix từng điểm

**Bước 1:** Fix `auth.repository.ts` — thay dynamic column bằng 2 functions riêng
```ts
// THAY VÌ:
// async function findAuthUserByColumn(column: 'id' | 'email', value: number | string) {
//   WHERE u.${column} = ?

// DÙNG:
async function findAuthUserByQuery(whereClause: string, value: number | string) {
  // ... WHERE clause is hardcoded string, not dynamic
}

export function findAuthUserByEmail(email: string) {
  return findAuthUserByQuery('u.email = ?', email);
}

export function findAuthUserById(id: number) {
  return findAuthUserByQuery('u.id = ?', id);
}
```

**Bước 2:** Audit DOMPurify usage frontend
- Tìm tất cả nơi render HTML: `dangerouslySetInnerHTML`
- Đảm bảo mỗi chỗ đều wrap bằng `DOMPurify.sanitize()`

**Bước 3:** Audit toàn bộ SQL queries cho raw string interpolation
```bash
cd backend/src
rg 'query\(' --type ts | rg '\$\{' | rg -v 'publishedAtSql'
# Tìm bất kỳ SQL query nào dùng template literal với biến ngoài
```

**Bước 4:** Thêm sanitization cho `publishedAtSql` — đây là trusted string nhưng nên refactor thành conditional parameter

### Plan B — Nếu refactor auth repository gây break

Giữ nguyên `findAuthUserByColumn` nhưng thêm runtime assertion:
```ts
if (column !== 'id' && column !== 'email') {
  throw new Error('Invalid column for auth user query');
}
```
