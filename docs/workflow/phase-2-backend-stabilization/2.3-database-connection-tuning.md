> **Yêu cầu trước:** Không

---

## Mô tả vấn đề

`backend/src/database/mysql.ts` connection pool cứng:
```ts
connectionLimit: 10,
queueLimit: 0,
```
- 10 connections có thể không đủ cho concurrent requests
- `queueLimit: 0` = unlimited queue → nếu pool hết connection, requests queue vô hạn
- Không có connection timeout

---

## Mục tiêu

1. Configurable connection pool qua `.env`
2. Thêm connection timeouts hợp lý
3. Thêm health check chi tiết hơn

---

## Cách thực hiện

### Plan A — Configurable pool

**Bước 1:** Thêm env vars vào `config/env.ts`:
```ts
database: {
  // ...existing
  connectionLimit: Number(process.env.DB_CONNECTION_LIMIT ?? 20),
  connectTimeout: Number(process.env.DB_CONNECT_TIMEOUT ?? 10000),
},
```

**Bước 2:** Sửa `database/mysql.ts`:
```ts
export const mysqlPool = mysql.createPool({
  host: env.database.host,
  port: env.database.port,
  user: env.database.user,
  password: env.database.password,
  database: env.database.name,
  waitForConnections: true,
  connectionLimit: env.database.connectionLimit,
  queueLimit: 100,
  connectTimeout: env.database.connectTimeout,
  enableKeepAlive: true,
  keepAliveInitialDelay: 30000,
});
```

**Bước 3:** Cập nhật `.env.example`

### Plan B — Nếu connection timeout gây vấn đề với slow queries
Tăng `connectTimeout` lên 30000ms hoặc loại bỏ.
