# Task 2.1 — Rate Limiting

> **Phase:** 2 — Backend Stabilization
> **Trạng thái:** ✅ Hoàn thành
> **Độ khó:** Thấp
> **Thời gian ước tính:** 30 phút
> **Risk nếu không làm:** 🔴 HIGH — Brute-force login, API abuse
> **Yêu cầu trước:** Không

---

## Mô tả vấn đề

Không có rate limiting → attacker có thể brute-force login endpoint, spam API requests.

---

## Mục tiêu

1. Rate limit login endpoint: 5 requests/phút/IP
2. Rate limit API chung: 100 requests/phút/IP
3. Rate limit upload: 10 requests/phút/IP

---

## Cách thực hiện

### Plan A — express-rate-limit (KHUYẾN NGHỊ)

**Bước 1:** Cài thư viện
```bash
cd backend && npm install express-rate-limit
```

**Bước 2:** Tạo `backend/src/middlewares/rate-limit.ts`
```ts
import rateLimit from 'express-rate-limit';

export const generalLimiter = rateLimit({
  windowMs: 60 * 1000,
  max: 100,
  message: { status: 'error', message: 'Too many requests. Try again later.' },
  standardHeaders: true,
  legacyHeaders: false,
});

export const authLimiter = rateLimit({
  windowMs: 60 * 1000,
  max: 5,
  message: { status: 'error', message: 'Too many login attempts. Try again later.' },
  standardHeaders: true,
  legacyHeaders: false,
});

export const uploadLimiter = rateLimit({
  windowMs: 60 * 1000,
  max: 10,
  message: { status: 'error', message: 'Upload rate limit exceeded.' },
  standardHeaders: true,
  legacyHeaders: false,
});
```

**Bước 3:** Mount trong `app.ts`
```ts
app.use('/api', generalLimiter);
app.use('/api/auth/login', authLimiter);
app.use('/api/media/upload', uploadLimiter);
```

**Bước 4:** Verify
```bash
# Gửi 6 login requests liên tục → request thứ 6 phải bị 429
for i in $(seq 1 6); do curl -s -o /dev/null -w "%{http_code}" -X POST http://localhost:4000/api/auth/login -H "Content-Type: application/json" -d '{"email":"test","password":"test"}'; echo; done
```

### Plan B — Nếu express-rate-limit gây vấn đề với proxy

Thêm `app.set('trust proxy', 1)` TRƯỚC khi mount rate limiter.

### Plan C — Nếu không muốn thêm dependency

Tự implement simple in-memory rate limiter bằng Map — nhưng không recommended cho production.
