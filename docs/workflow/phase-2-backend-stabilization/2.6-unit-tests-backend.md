## Cách thực hiện

### Plan A — Vitest (KHUYẾN NGHỊ, cùng ecosystem với Vite)

**Bước 1:** Setup
```bash
cd backend
npm install -D vitest @vitest/runner
```

Thêm vào `package.json`:
```json
"scripts": {
  "test": "vitest run",
  "test:watch": "vitest"
}
```

**Bước 2:** Test validators (pure functions, dễ nhất)
- `src/validators/__tests__/common.test.ts`
- Test `asRecord`, `optionalString`, `parsePositiveInteger`, etc.
- Test edge cases: null, undefined, empty string, wrong type

**Bước 3:** Test utilities
- `src/utils/__tests__/slug.test.ts` — test Vietnamese slug generation
- `src/utils/__tests__/http-error.test.ts`
- `src/utils/__tests__/password.test.ts` — hash + compare

**Bước 4:** Test auth validation
- `src/modules/auth/__tests__/auth.validation.test.ts`
- Test `validateLoginInput` với various inputs

**Bước 5:** Test post/user validation
- Tương tự cho các module khác

**Bước 6:** (Optional) Integration tests cho service layer
- Mock `mysqlPool.query` → test business logic
- Cần setup mock infrastructure

### Plan B — Jest thay vì Vitest

Nếu Vitest có issues với ESM:
```bash
npm install -D jest @types/jest ts-jest
```

### Plan C — Chỉ test validators trước

Nếu thời gian hạn chế: chỉ test shared validators + utilities. Đây là ROI cao nhất.
