## Mô tả vấn đề

Hiện tại DELETE posts/documents là **hard delete** — mất vĩnh viễn. Với school portal, admin có thể vô tình xóa tin tức quan trọng.

---

## Mục tiêu

1. Thêm `deleted_at` column cho `posts` và `documents`
2. DELETE → set `deleted_at = NOW()` thay vì xóa row
3. Tất cả queries mặc định exclude `WHERE deleted_at IS NULL`
4. Admin có thể xem và restore items đã xóa

---

## Cách thực hiện

### Plan A — Migration + refactor repository

**Bước 1:** Tạo migration `database/schema/014_add_soft_delete.sql`
```sql
SET @database_name = DATABASE();

-- posts.deleted_at
SET @col = (SELECT COUNT(*) FROM INFORMATION_SCHEMA.COLUMNS WHERE TABLE_SCHEMA = @database_name AND TABLE_NAME = 'posts' AND COLUMN_NAME = 'deleted_at');
SET @stmt = IF(@col = 0, 'ALTER TABLE posts ADD COLUMN deleted_at DATETIME NULL DEFAULT NULL', 'SELECT 1');
PREPARE s FROM @stmt; EXECUTE s; DEALLOCATE PREPARE s;

-- documents.deleted_at
SET @col = (SELECT COUNT(*) FROM INFORMATION_SCHEMA.COLUMNS WHERE TABLE_SCHEMA = @database_name AND TABLE_NAME = 'documents' AND COLUMN_NAME = 'deleted_at');
SET @stmt = IF(@col = 0, 'ALTER TABLE documents ADD COLUMN deleted_at DATETIME NULL DEFAULT NULL', 'SELECT 1');
PREPARE s FROM @stmt; EXECUTE s; DEALLOCATE PREPARE s;
```

**Bước 2:** Sửa `post.repository.ts`
- Thêm `AND p.deleted_at IS NULL` vào tất cả SELECT queries
- Thay `DELETE FROM posts` bằng `UPDATE posts SET deleted_at = NOW()`
- Thêm function `restorePost(id)` → `SET deleted_at = NULL`

**Bước 3:** Sửa `document.repository.ts` tương tự

**Bước 4:** Thêm API endpoints:
- `PATCH /api/posts/:id/restore`
- `PATCH /api/documents/:id/restore`
- `GET /api/posts?status=deleted` (admin only)

**Bước 5:** Cập nhật frontend admin pages — thêm filter "Đã xóa" và nút "Khôi phục"

### Plan B — Nếu soft delete quá phức tạp cho scope hiện tại

Chỉ thêm confirmation dialog ở frontend trước khi delete. Soft delete làm sau.

### Plan C — Dùng `archived` status thay vì soft delete

Thay vì xóa, chuyển status sang `archived`. Ít thay đổi code hơn nhưng semantics khác.
