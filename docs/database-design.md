# Thiết kế database

Database dùng PostgreSQL 18, chia thành các nhóm bảng chính:

- Người dùng: `users`
- Phân quyền: `roles`, `permissions`, `role_permissions`, `user_roles`
- Nội dung: `categories`, `posts`, `media_files`, `documents`
- Module trường học: `timetables`, `events`
- Hệ thống: `notifications`

## Định hướng

Các bảng dùng khóa chính `BIGINT GENERATED BY DEFAULT AS IDENTITY`, timestamp có timezone,
foreign key và check constraint. Nội dung JSON dùng `JSONB`; các trường tìm kiếm quan
trọng có index PostgreSQL phù hợp.

Migration PostgreSQL canonical nằm tại `database/postgresql/migrations` và seed tại
`database/postgresql/seeds`. Migration runner lưu checksum trong `schema_migrations`,
không cho sửa file đã chạy.

Các SQL MySQL trong `database/schema` và `database/seeds` chỉ giữ lại để tham chiếu
lịch sử, không còn được backend sử dụng.
